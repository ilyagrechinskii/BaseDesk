# Desktop — Александр

Рабочая область самостоятельного приложения Electron. Здесь пока только описание; `package.json`, main/preload и рабочая оболочка появятся в задаче Александра. Electron.NET не используется.

Оболочка отвечает за окно, жизненный цикл, общий каркас навигации и последующую интеграцию страниц из `src/frontend/pages/`. API — отдельное ASP.NET Core приложение, не сборочная зависимость Electron. Не копировать frontend в `desktop/` и не хранить здесь строку подключения PostgreSQL.

До интеграции согласовать с авторами экранов [контракт монтирования](../docs/frontend-conventions.md), с Натальей — единственный Sidebar, с Андреем — конфигурацию базового URL, origin и поведение при недоступном API. Управление запуском локального API требует отдельного решения.

Документы: [архитектура](../docs/architecture.md), [разработка](../docs/development.md). Команды запуска нового Electron ещё не существуют; старый профиль Desktop относится к прототипу.
