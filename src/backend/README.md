# Backend — Андрей

Рабочая область ASP.NET Core Web API (.NET 10), EF Core и PostgreSQL. Новый API пока не реализован. Предлагаемый каталог нового проекта — `BaseDesk.Api/`; его создание, зависимости, миграции и обновление решения входят в отдельную задачу Андрея.

Существующий `BaseDesk.App/` — сохранённый Electron.NET-прототип, а не основа запуска нового API. Пока не удалять его и не менять автоматически `BaseDesk.sln` или `global.json`; согласовать миграцию с Ильёй. Новый API не зависит от Electron и проверяется отдельными HTTP-запросами.

До реализации согласовать [DTO](../../docs/domain-models.md) и [HTTP-контракты](../../docs/api-contracts.md). Backend хранит бизнес-логику, валидирует запросы и связи, работает с БД через EF Core. Строки подключения и локальные секреты не коммитить. Версии пакетов и команды запуска задокументировать после создания реального проекта.

PostgreSQL и API через Docker Compose — следующий этап, готового Compose-файла сейчас нет. Полноценная авторизация, роли и удалённая синхронизация не входят в начальную реализацию.
