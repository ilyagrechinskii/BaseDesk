# Backend (ASP.NET Core Web API)

## Требования
- Windows 10
- .NET 10 SDK

## Сборка
Откройте PowerShell и выполните (Вместо F:\BaseDesk\BaseDesk\src\backend\Backend указать свое расположение): 
dotnet build --project F:\BaseDesk\BaseDesk\src\backend\Backend


## Запуск
dotnet run --project F:\BaseDesk\BaseDesk\src\backend\Backend

## API
curl.exe http://localhost:5261/api/health
