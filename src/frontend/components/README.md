# Общие компоненты — Наталья

Постоянная ветка: `natalia`. Здесь появятся повторно используемые HTML/JS/CSS-элементы по утверждённым изображениям: прежде всего общий Sidebar. Сейчас реализации нет.

Не дублировать компонент внутри каждого экрана. Экспорты, DOM-контракт, стили и способ подключения согласовать с Александром и авторами страниц до интеграции. Общие токены и базовые стили размещаются в соседнем `styles/`.

Разработчики страниц могут просматривать контент без Sidebar, пока компонент не готов. Компонент не должен требовать Electron, API или PostgreSQL для самостоятельной проверки. [Соглашения](../../../docs/frontend-conventions.md), [правила кода](../../../docs/frontend-coding-rules.md).
