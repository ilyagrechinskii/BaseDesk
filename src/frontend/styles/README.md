# Общие стили — Наталья

Постоянная ветка: `natalia`. Здесь появятся общие CSS-переменные с префиксом `--bd-`, базовые стили и типографика по утверждённым изображениям. Полноценные CSS-компоненты в архитектурной задаче не создаются.

Стили отдельных экранов остаются в их папках; повторяющиеся правила выносятся сюда после согласования. Владельцы страниц не меняют эти файлы без обсуждения. Существующий `../styles.css` относится к старому прототипу и автоматически не переносится в новую систему.
