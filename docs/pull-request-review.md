# Проверка и объединение Pull Request

Одна завершённая задача отправляется из постоянной именной ветки в `main`. Заголовок описывает результат; описание содержит ссылку на Issue, изменения, способ проверки и ограничения. Для Issue #1 допустима ссылка `Closes #1`, если PR действительно закрывает все его критерии.

Перед открытием PR автор проверяет:

- в сравнении с `origin/main` только файлы текущей задачи, без незавершённой следующей работы;
- нет секретов, `.env`, сборочных каталогов и случайных ресурсов;
- согласованы изменения общих файлов, DTO и интерфейсов экранов;
- документационные ссылки открываются, JSON корректен;
- для экрана приложены изображения результата и инструкция самостоятельного просмотра; для API — примеры проверенных запросов; для документации — список выполненных проверок.

Илья организует ревью; изменения общей области также проверяет её владелец. Андрей подтверждает API-контракты, Наталья — общие стили и компоненты, Александр — подключение экранов. Замечания исправляются небольшими коммитами в той же ветке, без изменения авторства предыдущих коммитов.

Reviewer оценивает соответствие Issue, границы ответственности, совместимость контрактов и воспроизводимость проверки. Предварительные решения не объявляются согласованными до ответа владельца. Наличие PR само по себе не является разрешением на объединение.

После одобрения пользователь с правами объединения выполняет merge через GitHub. Предпочтительный способ — **Create a merge commit**; он сохраняет подготовленные логические коммиты. Если настройки репозитория разрешают только иной способ, Илья сначала согласует его с командой. Не включать автоматическое удаление постоянной именной ветки и не удалять её вручную.

После объединения автор синхронизирует свою ветку с `origin/main` по [team-workflow.md](team-workflow.md), проверяет пустую разницу до начала следующей задачи. Защита `main`, обязательные review и запрет удаления именных веток рекомендуются как настройки GitHub; эта задача не меняет настройки репозитория и не утверждает, что защита уже включена.
